Interlock v3 — a pause that crosses chains

The core Interlock demo pauses a vault that lives on the same chain as the judge. v3 extends the same pattern across a bridge: when GenLayer consensus confirms an exploit in a vault's audit log, Interlock v3 emits a narrowly-typed TRIP message toward a Base Sepolia contract (BaseDemoVault), which flips its paused flag.

The judgment is the same as always — pinned on-chain evidence, independent validator re-derivation, deterministic guard. The delivery is new: a LayerZero V2 bridge with an off-chain relay, on a hub-and-spoke model anchored at zkSync Era Sepolia.

How a trip works

  1. Report. Anyone posts a bonded report naming one operation in the GenLayer DemoVault audit log.
  2. Consensus judges. GenLayer validators independently re-classify the pinned entry. Only a closed-enum verdict matters.
  3. Outbox. On EXPLOIT_CONFIRMED, interlock_v3.py calls the Foundation's BridgeSender.send_message(...) with the exact tag "TRIP" — never a generic arbitrary-call payload.
  4. Relay. The Node.js relay polls the GenLayer outbox and calls BridgeForwarder.callRemoteArbitrary on zkSync Era Sepolia with the LayerZero fee.
  5. Delivery. LayerZero delivers to Base Sepolia; the destination receiver dispatches processBridgeMessage to BaseDemoVault.
  6. Paused. BaseDemoVault.paused flips to true — observable on Base Sepolia. Only the owner can resume.

Trust boundary — read this before believing the demo

  • BaseDemoVault is a toy, not Aave. It has one deliberate flaw (borrow with no health check) and protects no real funds. v3 makes no claim to protect real Aave, real Base mainnet funds, or anything beyond this toy contract.
  • The destination chain trusts the relay. The message that flips paused is delivered by an off-chain relay service. There is no independent finality proof binding an outbound message to GenLayer validator consensus. Today the model is trusted-relay, not consensus-authenticated. Same-chain Interlock never has this problem.
  • The relay is a real operational dependency. If it is not running, a real GenLayer-side trip will never reach Base Sepolia. A trip is not instant, and not guaranteed, without it.
